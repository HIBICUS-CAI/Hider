## CT-58: パイプライン全体（CPU ラスタ、1920×1080）

`dotnet test tests/Hider.Core.Tests -c Release --filter CT58 --logger "console;verbosity=detailed"` の出力。ウォームアップ後の 1 回。準備（前段ぼかし・ピラミッド）+ 描画 + テスト側の面の作成と読み戻し（13.8 ms）を含む。

| 日付 | 環境 | RID | 描画モード | 内容 | ms |
|---|---|---|---|---|---|
| 2026-10-11 | 作業コンテナ（Xeon 2.8 GHz） | linux-x64 | CPU | ピクセル化（ブロック 12） | 51.0 |
| 2026-10-11 | 同上 | linux-x64 | CPU | 前段ぼかし 8 + ピクセル化 | 89.5 |
| 2026-10-11 | 同上 | linux-x64 | CPU | ピクセル化 + 色数 8 | 51.1 |
| 2026-10-11 | 同上 | linux-x64 | CPU | 生成ブロック | 34.8 |
| 2026-10-11 | 同上 | linux-x64 | CPU | 生成ブロック（目地 2 px） | 42.0 |

所見:

- 支配項はピラミッドの作成（CPU で 1080p あたり約 30 ms）。800×450 のエリアなら 1 フレームあたり 5〜7 ms 程度。GPU 描画時はピラミッドも GPU 上で作る。
- 生成パターンは FR-42 の読み替えどおりサイズ・値が変わった時だけ描き、再描画はキャッシュ画像の複写になる（CT-57、GT-25）。目地付きブロックは目地を矩形で塗ることでセル単位評価のまま描く（全画素評価では 579 ms だった）。
- モザイクも取得フレーム・値・サイズが変わった時だけパイプラインを通し、再描画はキャッシュ画像の複写（GT-23）。
