# S-1: 枠なし・最前面・非アクティブ・透明窓 + トレイ（Windows 11）

設計書 §10 S-1。合否: 左クリックで自前メニューが出る。窓がフォーカスを奪わない。

## 手順

1. メモ帳を開き、文字を入力できる状態（キャレットが点滅）にしておく。
2. 別のターミナルで `dotnet run --project spikes/S-1` を実行する（.NET 10 SDK が必要）。
3. 画面中央に灰色の市松模様の窓（400×240）が出る。以下を確認する。

| # | 操作 | 期待 |
|---|---|---|
| 1 | 起動直後にメモ帳へキー入力 | 入力がメモ帳に入る（窓がフォーカスを奪っていない）。ログに `ACTIVATED` が出ない |
| 2 | メモ帳のタイトルバーをクリック | 市松模様の窓がメモ帳より上に残る |
| 3 | タスクバー / Alt+Tab | 市松模様の窓が出ない |
| 4 | トレイアイコン（モザイク柄）を左クリック | カーソル付近に枠なしの小窓メニュー（新しいエリアを追加 / 終了）が出る。ログに `tray: Clicked` |
| 5 | トレイアイコンを右クリック | OS のメニューで同じ項目が出る |
| 6 | 「新しいエリアを追加」 | 2 枚目の窓が出て、同じくフォーカスを奪わない |
| 7 | 窓をダブルクリック | ログに `double click` |

## 返してほしい情報

- 上表 1〜7 の結果（OK / NG とメモ）
- コンソールログ全文（特に `opened ... transparency=` と `render: skia lease=... gpu=...` の行）
- 左クリックメニューのスクリーンショット 1 枚
