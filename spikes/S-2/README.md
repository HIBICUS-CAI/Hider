# S-2: S-1 + ARGB visual の GLX 描画 + 帯の透明化（Ubuntu 26.04 / GNOME 50 / XWayland）

設計書 §10 S-2。合否: 透明帯の下が実際に見える。Topmost が Wayland ネイティブ窓より上。

プログラムは S-1 と共通（`--strip` で 8 px の完全透明な帯が 250 ms ごとに下へ移動する）。

## 手順

1. Wayland セッションでログインしていることを確認する（`echo $XDG_SESSION_TYPE` → `wayland`）。AppIndicator 拡張は有効のまま。
2. 端末（Wayland ネイティブ）と Firefox を開き、文字が見える状態にしておく。
3. `dotnet run --project spikes/S-1 -- --strip` を実行する。

| # | 操作 | 期待 |
|---|---|---|
| 1 | 窓を端末の文字の上に重ねる（窓は中央に出る。端末側を動かす） | 透明帯の部分だけ下の文字が見え、帯が上から下へ移動する |
| 2 | 端末・Firefox をクリック | 市松模様の窓が上に残る |
| 3 | 起動直後のキー入力 | 端末に入る（フォーカスを奪わない） |
| 4 | トレイアイコンを左 / 右クリック | AppIndicator のメニューが出る（左右とも） |
| 5 | AppIndicator 拡張を無効にして再起動 | トレイが出ないこと（D-9 のフォールバックは本体で実装） |
| 6 | 設定 → ディスプレイで 125% / 150% にして再起動 | ログの `scaling=` の値と見た目のサイズ |

## 返してほしい情報

- 上表の結果、コンソールログ全文（`transparency=Transparent`、`gpu=True` になるか）
- 帯が透けている瞬間のスクリーンショット（または短い録画）
- `glxinfo -B | head -20` の出力（GPU / ドライバ）
