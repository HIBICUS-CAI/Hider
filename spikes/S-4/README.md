# S-4: PrintWindow(PW_RENDERFULLCONTENT) で黒になる窓の種類（Windows 11）

設計書 §10 S-4。合否: 黒になる種類の一覧と、黒検出（全画素 0）の信頼性。

## 手順

1. 次を開いておく: Edge、VS Code、設定アプリ（UWP）、管理者として実行したコマンドプロンプト、デスクトップ（壁紙とアイコン）、
   排他全画面のゲームまたは動画（可能なら）、DRM 付き動画（Netflix 等、可能なら）。
2. 通常権限のターミナルで `dotnet run --project spikes/S-4 -- --save s4-out` を実行する。
3. 同じことを管理者のターミナルでも 1 回行う（結果の差を見る）。
